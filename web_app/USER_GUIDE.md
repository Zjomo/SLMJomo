## 🎨 核心功能

### 1. ⚙️ 实时参数调整

#### 基础参数
- **焦距**: 100-5000mm，滑块实时调整
- **波长**: 355-1064nm，支持快捷按钮
  - 蓝光 473nm
  - 绿光 532nm
  - 红光 633nm
  - 红外 1064nm

#### 高级参数
- **旋转角度**: 0-360°
- **缩放因子**: 0.1-5.0
- **X/Y偏移**: -500到500像素

#### 图像参数
- **分辨率**: 自定义宽度×高度（最大4096×4096）
- **像素间距**: 1.25μm（高分辨率）或20μm（标准）
- **输入图像**: 支持上传图像并叠加相位

### 2. 💾 预设管理

- ✅ 保存当前参数配置为预设
- ✅ 快速应用预设配置
- ✅ 删除不需要的预设
- ✅ 预设数据持久化存储（SQLite）

### 3. 📊 实时预览

- ✅ 相位图实时生成和显示
- ✅ 相位分布曲线可视化
- ✅ 参数信息实时更新
- ✅ 历史记录跟踪

### 4. 📥 导出功能

- ✅ 一键下载生成的相位图
- ✅ 自动文件命名（包含参数信息）
- ✅ 支持BMP和PNG格式

## 🔬 技术架构

### 后端（Flask）
- **框架**: Flask 2.3+
- **数据库**: SQLite + Flask-SQLAlchemy
- **图像处理**: NumPy + Pillow
- **API**: RESTful设计，返回JSON数据

### 前端（原生JavaScript）
- **UI框架**: 纯HTML/CSS/JS（无依赖）
- **样式**: 响应式设计，渐变主题
- **交互**: Fetch API + Canvas API
- **实时更新**: DOM操作 + 事件监听

### 数据库模型
- **PresetConfig**: 参数预设配置表
- **GenerationHistory**: 生成历史记录表

## 📋 API接口文档

### 生成相位图
```
POST /api/generate
Content-Type: application/json

请求体:
{
  "focus_mm": 1000,
  "wavelength_nm": 532,
  "x_pixels": 1272,
  "y_pixels": 1024,
  "pitch_mode": 1,
  "rotation_degree": 0,
  "offset_x": 0,
  "offset_y": 0,
  "scale_factor": 1.0,
  "input_image": "data:image/png;base64,..." // 可选
}

响应:
{
  "success": true,
  "image": "data:image/png;base64,...",
  "filename": "fresnel_f1000mm_w532nm_20260728_172440.bmp",
  "filepath": "output_phase_patterns/...",
  "message": "相位图生成成功"
}
```

### 预设管理
```
GET    /api/presets          # 获取所有预设
POST   /api/presets          # 保存新预设
DELETE /api/presets/<id>     # 删除预设
```

### 历史记录
```
GET /api/history             # 获取生成历史
```
