# 🎯 LCOS-SLM 专业控制面板使用指南

## 📋 界面版本说明

本项目提供**两个版本**的Web界面：

### 🔹 基础版（推荐初学者）
- **访问地址**: http://127.0.0.1:5000/
- **特点**: 简洁直观，快速上手
- **适用场景**: 单次相位图生成、参数调整

### 🔹 专业版（模拟官方SLM软件）
- **访问地址**: http://127.0.0.1:5000/pro
- **特点**: 完整功能模块，专业级UI设计
- **适用场景**: 复杂工作流、序列播放、设备控制

## 🎨 核心功能详解

### 1. 设备连接管理

**连接设备**
```javascript
点击"连接设备"按钮
→ 模拟设备连接
→ 状态更新为"已连接"
→ 显示设备信息
```

**状态监控**
- 实时显示连接状态
- 设备信息可视化
- 断线自动提示

### 2. 序列播放功能

**添加到序列**
```
1. 生成相位图
2. 点击"添加到序列"
3. 序列列表中显示新项
```

**播放序列**
```
1. 设置播放间隔（默认1000ms）
2. 勾选"循环播放"（可选）
3. 点击"播放"按钮
4. 自动切换显示图案
```

**暂停/停止**
- 暂停：保持当前帧
- 停止：返回第一帧

### 3. 参数调整技巧

**快捷波长选择**
- 直接点击波长按钮
- 自动更新输入值
- 高亮显示当前选择

**实时滑块调整**
- 拖动滑块实时预览
- 输入框精确控制
- 双向同步更新

**参数重置**
- 点击模块右上角🔄按钮
- 一键恢复默认值

### 4. 图像处理

**上传图像**
- 支持拖拽上传
- 自动缩放适配
- 实时预览显示

**叠加相位**
- 上传图像后生成
- 自动叠加相位效果
- 保持相位调制特性
