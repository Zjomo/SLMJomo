# 🎯 LCOS-SLM 专业控制面板使用指南

## 📋 界面版本说明

本项目提供**两个版本**的Web界面：

### 🔹 基础版（推荐初学者）

## 🎨 核心功能详解

### 1. 设备连接管理

**模拟连接**
```javascript
点击"模拟连接"按钮
→ 模拟设备连接
→ 状态更新为"模拟已连接"
→ 不会连接或控制真实 SLM
```

**状态监控**
- 实时显示连接状态
- 设备信息可视化
- 断线自动提示

### 2. 序列播放功能

**添加到序列**
```
1. 生成相位图
2. 点击"添加到序列"
3. 序列列表中显示新项
```

**播放序列**
```
1. 设置播放间隔（默认1000ms）
2. 勾选"循环播放"（可选）
3. 点击"播放"按钮
4. 自动切换显示图案
```

**暂停/停止**
- 暂停：保持当前帧
- 停止：返回第一帧

### 3. 参数调整技巧

**快捷波长选择**
- 直接点击波长按钮

**实时滑块调整**
- 拖动滑块实时预览
- 输入框精确控制
- 双向同步更新

**参数重置**
- 点击模块右上角🔄按钮
- 一键恢复默认值

### 4. 图像处理

**上传图像**
- 支持拖拽上传
- 自动缩放适配
- 实时预览显示

**叠加相位**
- 上传图像后生成

## SLAM 三光斑独立运动

专业版导航中的“SLAM 三光斑运动”模块可导入显微镜图像、标记材料、设置标定原点，并把三份材料位置分别分配给三个光斑。`px/μm` 是样品图像标定比例，界面同时显示倒数 `μm/px`；焦平面 X/Y 比例默认 1:1 且可修改。50× 仅作为记录参数，不会再次乘入已标定比例。请通过实际样品位置确认 X/Y 比例和坐标方向后再用于光路控制。

默认参数为焦距 1000 μm、波长 532 nm、放大倍率 50×、6 mm 入射光束、目标焦斑 6 μm、SLM 1272×1024 px、运动速度 2 μm/s。目标斑按焦平面 `1/e²` 强度直径设置，允许范围为 5–8 μm。路径按弧长和帧间隔采样，三个光斑共享时间轴；任何帧中光斑距离小于所设目标直径时，服务端会拒绝生成。

生成算法包括通用等强光栅、高斯优化、1×3 达曼和标准三焦点。达曼算法要求整个序列保持水平等间距三点；其它算法对任意坐标的适用范围以当前生成器校验为准。每项任务最多 200 帧。生成后可逐帧查看相位图及傅里叶重建图，选择“加入 CGH 序列”后可在 CGH 视频序列中播放；播放器使用路径帧时长，重建图模式显示已解码的焦平面强度结果。

相位 BMP、傅里叶重建 PNG 和 manifest 写入 `web_app/output/Lingo/YYYYMMDD/<job-id>/`，根目录可由 `SLMJOMO_LINGO_OUTPUT_DIR` 配置。ZIP 导出仅打包相位图。项目保存显微镜图像、标定、材料分配、路径和参数，不包含 SLAM 帧图片；重新打开项目后需重新生成帧，再加入 CGH 序列。

USB 上传仅接受 1272×1024 灰度相位图，使用用户指定的 FMem 起始槽位及其后连续槽位，设备共有 0–818 共 819 个易失槽位。上传前勾选覆盖确认；服务端拒绝模拟驱动、断连设备、槽位越界及正在播放的设备。批量上传在控制器锁内完成状态检查、旧槽位备份、写入和首帧切换；任一写入失败会尝试恢复目标槽位，并在响应中列出恢复失败的槽位。USB 的帧时长表示切槽命令等待间隔，不保证等于液晶响应时间；规划速度、真实光斑直径和运动轨迹均需使用匹配波长 LUT 与实体光路验证。单任务还受总估算像素量和完成任务数量限制，防止高分辨率序列无限占用磁盘与内存。
