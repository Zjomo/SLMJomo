# SLAM 三光斑独立运动计划

## 目标

在 Web 专业面板增加三光斑独立运动工作区：导入显微镜图像并标记材料，完成像素到微米的标定，为三个光斑分别规划路径，逐帧生成相位图，并支持仿真播放、项目保存、日期目录导出、ZIP 下载和 USB_SLMControl 序列播放。

## 现状与约束

- `web_app/app.py` 的 `SLMPatternGenerator.fresnel_three_spots()` 已有 analytic、uniform_grating、dammann、gaussian_wgs 算法和自由二维坐标入口；当前只有 `gaussian_wgs` 接受自由二维点位，其他分支生成规则水平阵列。现有焦距及生成器焦平面坐标使用 mm，波长使用 nm，SLM 像素间距使用 μm。
- `web_app/static/js/pro_main.js` 已有 CGH 视频序列、播放器和项目 v2 的 CGH 序列持久化；序列当前上限为 200 帧，可复用就绪帧播放和现有导出交互。
- `web_app/app.py` 已有傅里叶相位图解码和 CGH 序列 ZIP 导出接口。SLAM 任务逐帧生成相位图时即调用单帧 `FourierSimulator.run_simulation()` 生成重建图；完成后交接到 CGH 视频序列的是已计算相位与重建帧，不会再把 SLAM 相位当作目标图送入 CGH 相位恢复。CGH 视频序列上限为 200 帧。
- `web_app/usb_slm_control.py` 与 `web_app/usb_slm_routes.py` 已提供真实驱动、32 位桥接、模拟驱动、FMem 写入和硬件序列播放；硬件图像固定为 1272×1024，FMem 槽位为 0–818。`auto` 可回退模拟驱动，实时控制必须拒绝模拟驱动并检查帧数/可用槽位。
- 厂商 USB SDK 手册确认 FMem 共 819 个易失槽位；序列时长表示 PC 发出切槽命令后等待到下一命令的时间，不保证等于液晶稳定响应时间。X15223 手册还指出相位响应依赖波长 LUT，另有波前畸变校正图；无对应校准时只能报告数值仿真/命令播放，不能承诺实测焦斑和速度。
- 仓库已有未提交和未跟踪的 CGH 序列、USB 控制及 UI 改动。本功能实现时以当前工作树为基线，保留这些改动，只做必要的增量兼容。

## 参数解释与初始假设

- 焦距 UI 使用 μm，默认 1000；调用现有生成器前换算为 1.0 mm。波长默认 532 nm，倍镜默认 50×，入射光束直径默认 6 mm，输出分辨率默认 1272×1024 px。
- 目标焦斑尺寸按直径输入，默认值取 5–8 μm 范围内的 6 μm；若算法接口接收半径，则换算为 mm 后传入。界面明确显示尺寸定义和单位。
- 标定输入以 `px/μm` 为准，并同时显示倒数 `μm/px`；用于将显微镜图像中的点转换为样品平面坐标。原点由用户在图像中设置。显微镜图像 y 轴向下与光学坐标 y 轴方向的映射必须固定并在预览中可见。
- 50× 倍镜参数随路径与项目保存并显示；实际坐标换算以用户输入的 px/μm 标定为准，避免在没有相机像元尺寸时重复乘入放大倍率。
- 样品平面坐标再经过单独定义的样品平面到生成器焦平面变换，才作为 `target_spots.x_mm/y_mm` 输入；不能把样品 μm 直接当成焦平面 mm。当前参数不足以确认 50× 是否是两平面间的有效倍率，首版用可编辑的 X/Y 比例实现 1:1 默认值；此比例需在实际光路中标定。
- 浏览器可用 `getUserMedia` 读取实时摄像头，或用用户主动发起的 `getDisplayMedia` 共享显微镜软件画面；本地文件仍可导入。ROI 由画面拖拽选择，标记与原点使用所选 ROI 的像素坐标。浏览器安全策略要求 localhost/HTTPS 和用户明确媒体权限；媒体流不发送到后端。项目保存实时流当前 ROI 的 PNG 快照，以便恢复离线编辑。
- 两点距离标定遵循 `Calibration.py` 的比例计算：用户输入参考长度 μm，点击 ROI 内两个标尺端点，使用像素欧氏距离除以参考长度得到 `px/μm`，同时显示倒数 `μm/px`；`slam_motion.py` 再将校准坐标传入路径规划。
- 三条路径共享一条时间轴，按弧长以配置速度（默认 2 μm/s）插值；路径较短的光斑在终点停留。帧间隔可配置，并在生成前按 200 帧序列上限校验。若任意同一时刻两个光斑重合或小于所选算法的最小间距，整次规划在写文件前失败，不输出部分序列；仅几何路径相交但发生在不同时刻不作为碰撞。
- Gaussian WGS 支持自由二维点位。标准解析三焦点需扩展为任意三个二维位置；均匀光栅只支持等间距线性衍射级次，1×3 达曼只支持规则三点结构。逐帧违反所选算法几何约束时明确拒绝并说明可选算法，不静默替换算法。
- 5–8 μm 目标尺寸首版按焦平面 `1/e²` 强度直径解释；Gaussian WGS 接口使用半径，传入值为该直径的一半并转换到 mm。UI 标明该定义。
- 项目文件保存显微镜源图（受现有图像预算限制）、标定、材料和路径参数，不内嵌最多 200 张全分辨率相位图；CGH 序列序列化时跳过 SLAM 帧，重开项目后由保存的路径参数重新生成并再次加入序列，历史输出仍可从输出目录/ZIP 获取。
- 浏览器预览或模拟驱动通过不代表实体光学效果已验证。相位 LUT、设备方向和真实运动仍需通过实体 SLM 校准。

## 显微镜光斑反馈优化计划

目标是在不识别材料或解释整幅显微镜画面的前提下，只测量三个已知光斑位置，并将实测偏差用于修正对应 CGH 目标。现有 USB 接口上传预先生成的帧序列，不提供相机帧与 SLM 当前帧的同步，因此本次实现定位为人工同步的“测量—补偿—重算”迭代校准。

### `task_list`

- [x] **1. 盘点现有坐标与设备流程**：确认实时视频、ROI、`px/μm`、原点和 X/Y 映射在浏览器侧；后端按焦平面坐标生成每帧相位图；USB/CGH 使用已生成序列，没有运行中相机反馈接口。
- [x] **2. 增加局部亮斑检测器**：操作者按编号点选亮斑附近，检测器只分析局部窗口；以窗口边缘估计背景和噪声阈值，用连通区域与限幅亮度权重求质心，忽略孤立热像素并拒绝低对比度、过大或触及搜索边界的候选区。
- [x] **3. 实现位置误差测量与路径补偿**：对齐当前选中相位帧的计划坐标与显微镜实测质心，依现有原点、`px/μm` 和 X/Y 比例换算误差；用户确认后以可调增益对三个光斑的全部路径点分别施加补偿。
- [x] **4. 衔接现有 CGH 工作流**：补偿后的坐标直接进入现有运动任务 API，复用 Fresnel 三焦点生成、傅里叶重建、序列播放、ZIP 导出及 USB 上传；原有路径/视场/最小间距校验继续生效。
- [x] **5. 保存状态与交互边界**：项目保存补偿量、搜索半径和增益；重新标定、换 ROI 或换显微镜图像时清除过期的测量/补偿。
- [x] **6. 添加自动化验证并更新文档**：合成亮斑覆盖渐变背景、噪声、孤立亮像素、无有效亮斑和搜索边界；UI 合约验证误差换算、补偿方向、路径 payload 与项目状态往返。实体 SLM 和相机同步需另行实测。

### 已知限制

- 反馈测量前须选择正确的相位帧，并确保它就是实体 SLM 当前显示的帧；启动反馈测量会冻结当前显微镜画面，以保证三个点来自同一图像。
- 操作者需要依次选择光斑编号并点选亮斑附近。检测器不会自动在全画面寻找三个候选，因此远处材料亮点不容易被误配为目标光斑。
- 局部背景扣除和噪声阈值能缓解渐变背景与孤立噪点，不能保证处理强散斑、明显饱和、叠在一起的亮斑或低信噪画面；质量不合格时不应用误差。
- 补偿只平移各光斑的目标路径，不修正焦斑尺寸、强度均匀性、光路像差、LUT 或 SLM 波前误差。
- 当前不是播放中逐帧自动闭环。实现真正实时闭环需要同步控制 SLM 单帧显示、等待液晶稳定、相机曝光/采集、编号跟踪和下一帧相位重算。
