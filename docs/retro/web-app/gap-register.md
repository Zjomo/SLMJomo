- `USB_Control_SDK/project/main.py` loads the matching bundled cdecl DLL only when run and closes the device after query failures; path selection and smoke-flow behavior have tests, but no device call was made.
- The SDK smoke script is import-safe and closes the opened device in a `finally` block; six fake-DLL tests cover success, read failures, no-device, capacity overflow, and import behavior. It still only reads serial/temperature and does not transfer patterns.

The SDK manual documents the required image size, frame-memory slots, separate display operation, and reboot-required USB mode change; it does not specify BMP path encoding. Generated phase images also require model/wavelength calibration, so physical validation is still required before integration.
